Teaching & interactive labs

Teaching Assistant · University of Washington Bothell · 2016–2017

Prepared six repositories for hands-on teaching, including interactive malware reverse-engineering labs. These resources cover Android application behavior, mobile-system observation, and application development.

Historical educational materials. Some examples deliberately demonstrate harmful application behavior. Analyze them only in isolated, disposable lab environments with synthetic data, never on personal or production devices. These repositories are not live demos and may require older tooling.

  • Password SnifferAndroid lab demonstrating the security implications of insecure inter-application messages.
  • Trojan RecipeAndroid lab for analyzing unwanted behavior hidden in an apparently ordinary application.
  • TicTacToe MalwareAndroid malware-analysis lab exploring background behavior and destructive side effects.
  • Parameter Collection ServiceMobile-system parameter logging developed in the context of investigating cellular-network anomalies.
  • Parameter Collection Test AppAdditional teaching resource in the parameter-collection project.
  • Mood Sense AppSpring Boot and MySQL application with documented application components and data handling.
